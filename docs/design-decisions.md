# 设计决策

1. **零依赖内核**：受限环境也能跑；最小张量库够用即可。
2. **确定性 mock**：训练/评测可复现；skill 门控 + 单调信号保证曲线漂亮。
3. **skill 单调趋 1**：训练信号恒为正，避免「对 +1 错 -1」把 skill 压到 0。
4. **确定性哈希**：`md5(key)` 前 8 字节种子驱动 `random.Random`，熵足且快。
5. **YAML 回退**：无 PyYAML 时用极简解析器。
6. **后端注册**：装饰器 `@register_backend(name)`，`__init__.py` 显式导入各后端以触发注册。
7. **CLI 共享 --config**：通过 `parents=[common]` 让子命令继承。
